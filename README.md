# 💳 Hostel Wallet - Expense Management System

A modern, user-friendly expense tracking application designed specifically for hostel students to manage their finances effectively.

![Hostel Wallet](https://img.shields.io/badge/Version-1.0.0-blue)
![License](https://img.shields.io/badge/License-MIT-green)
![Made with Love](https://img.shields.io/badge/Made%20with-❤️-red)

## 🎯 Features

- **💰 Track Income & Expenses** - Add, view, and manage all your transactions
- **📊 Visual Analytics** - Beautiful pie chart showing spending by category
- **📱 Responsive Design** - Works perfectly on mobile, tablet, and desktop
- **🎨 8 Categories** - Food, Transport, Shopping, Entertainment, Education, Health, Income, Other
- **💾 Local Storage** - All data saved locally in your browser
- **🔍 Smart Filtering** - Filter transactions by type (All/Income/Expense)
- **📅 Date Tracking** - Keep track of when transactions occurred
- **🗑️ Delete Option** - Remove unwanted transactions easily

## 📦 Installation

1. **Clone or Download** this repository:
   ```bash
   git clone https://github.com/adityakajala/hostel-wallet.git
   ```

2. **Open the project folder**:
   ```bash
   cd hostel-wallet
   ```

3. **Open `index.html`** in your browser:
   - Double-click the file, or
   - Right-click → Open with → Your browser

That's it! No build process, no dependencies to install.

## 💡 How to Use

1. **Add a Transaction**:
   - Fill in the description (e.g., "Lunch at canteen")
   - Enter the amount
   - Select a category
   - Choose the date
   - Select transaction type (Expense or Income)
   - Click "Add Transaction"

2. **View Your Balance**:
   - See your total balance, income, and expenses in the top cards

3. **Analyze Spending**:
   - Check the pie chart to see which categories you spend most on

4. **Filter Transactions**:
   - Use "All", "Income", or "Expense" buttons to filter the list

5. **Delete Transactions**:
   - Click the "Delete" button on any transaction to remove it
